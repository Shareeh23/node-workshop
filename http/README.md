# HTTP

Practical exercises for understanding HTTP and implementing HTTP functionality using Node.js core APIs, without relying on Express.

## Objective

Build a practical understanding of HTTP by implementing servers, routing, request parsing, responses, status codes, headers, streaming, and basic command-line utilities using Node.js core APIs.

## Exercises

- [x] Create an HTTP server from scratch
- [x] Create a server with multiple routes
- [x] Return different responses based on the HTTP method
- [ ] Parse URL query parameters
- [ ] Parse URL path parameters
- [x] Read and parse a JSON request body
- [x] Return different HTTP status codes based on the request
- [ ] Set custom response headers
- [x] Implement a basic JSON API without Express
- [ ] Implement a simple request logger
- [ ] Implement a basic 404 handler
- [ ] Serve an HTML file using `fs`
- [ ] Stream a large file instead of loading it entirely into memory
- [ ] Create a file-copy utility using streams
- [ ] Create a simple CLI tool using `process.argv`
